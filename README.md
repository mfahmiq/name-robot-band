# Name the Robot Band

One funny name for a band made of robots, plus a few words on its hit song:

> The Roombas — hit single "Suck It Up", sweeping the charts one floor at a time

78 characters. The joke stacks three laughs into one line: the band is literally a fleet of robot vacuums, the hit song title "Suck It Up" is both what a vacuum does and the classic tell-off, and the tagline "sweeping the charts one floor at a time" puns chart success against vacuuming floors. It lands on the first read with no setup, the song line adds a second laugh that fits the band's name exactly, and "The Roombas" sounds like a band you would actually repeat to a friend. No filler, no explaining the joke.

## How to run

```sh
python3 main.py
```

This writes the entry verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
